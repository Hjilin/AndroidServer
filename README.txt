简云plus (JianYun) - Android 手机上的全能 Web 服务端

版本: 1.2
最低支持: Android 7.0 (API 24)
目标版本: Android 14 (API 34)


== 项目简介 ==

简云plus是一款运行在 Android 设备上的服务端管理工具。无需 ROOT，即可将手机/平板变
为功能完整的 Web 服务器，集成 Nginx、PHP、MariaDB、Redis、FTP、WebSocket 和内
网穿透，适合开发者调试、学习建站、内网服务搭建等场景。


== 功能特性 ==

1. 智能仪表盘
   实时监控内存/存储/网络流量，组件运行状态一目了然，内外网 IP 自动获取

2. 四合一 Web 服务
   Nginx + PHP + MariaDB + Redis 独立开关，支持自动启动

3. 组件下载中心
   内置下载管理器，支持多版本选择和断点续传

4. 网站管理
   添加/删除站点，自动生成 PHP 演示页，端口冲突检测

5. FTP 文件服务
   基于 Apache FtpServer，多用户管理，公网/内网访问可控

6. WebSocket 服务端
   Token 认证、IP 封禁系统、连接限速、消息缓冲区、客户端管理

7. 内网穿透 (cpolar)
   一键暴露本地服务到公网，支持国内/海外多区域

8. phpMyAdmin
   浏览器中管理 MariaDB 数据库

9. 10 套主题
   Slate / Blue / Green / Purple / Orange / Red / Cyan / Pink / Indigo / Brown

10. 权限引导
    文件管理 -> 电池白名单 -> 通知权限，分步完成

11. 应用内更新
    远程检查版本，支持 changelog 展示和强制更新
